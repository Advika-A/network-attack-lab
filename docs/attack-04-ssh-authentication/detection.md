# Attack 04 Detection – SSH Failed Authentication Detection

## Overview

This detection identifies repeated failed SSH authentication attempts by analyzing the Ubuntu authentication log (`auth.log`). Instead of inspecting network packets, the detector examines host-based log events generated by the OpenSSH server to identify repeated login failures originating from the same source IP address.

The implementation demonstrates a simple threshold-based approach for detecting potential SSH brute-force activity.

---

## Detection Objective

Detect repeated failed SSH login attempts recorded in the Ubuntu authentication log.

## Detection Logic

The detection performs the following steps:

1. Opens the authentication log.
2. Searches for entries containing **Failed password**.
3. Extracts:
   - Timestamp
   - Username
   - Source IP
4. Groups failed logins by source IP.
5. Counts failed authentication attempts.
6. Compares the count against a configurable threshold.
7. Generates an alert for sources exceeding the threshold.

---

## Detection Strategy

Repeated failed SSH login attempts are commonly associated with password guessing and brute-force attacks. By monitoring authentication logs and counting failures from each source IP, defenders can identify suspicious login activity before a successful compromise occurs.

---

## Implementation

Detection script:

```
detections/python/detect_ssh_failures.py
```

Example execution:

```bash
python detections/python/detect_ssh_failures.py logs/attack-04/auth.log
```

Custom threshold:

```bash
python detections/python/detect_ssh_failures.py logs/attack-04/auth.log --threshold 5
```

---

## Potential False Positives

Repeated authentication failures may also occur during:

- Users entering incorrect passwords.
- Administrative troubleshooting.
- Automated configuration scripts.
- Misconfigured applications attempting authentication.

Detection results should be interpreted alongside operational context.

---

## Limitations

This implementation:

- Operates on offline log files.
- Uses a configurable threshold-based approach.
- Detects only failed password authentication events.
- Does not correlate authentication events across multiple systems.
- Does not detect successful logins following repeated failures.

---

## Defender Perspective

Authentication logs provide reliable evidence of login activity and are an essential source for detecting password guessing and brute-force attacks. Monitoring failed login attempts enables defenders to identify suspicious authentication behavior and respond before unauthorized access is achieved.

---

## Key Takeaways

- Authentication logs provide valuable visibility into SSH login activity.
- Grouping failed logins by source IP enables simple behavioral detection.
- Threshold-based monitoring offers an effective approach for identifying brute-force attempts.
- Host-based log analysis complements network traffic analysis within a layered defense strategy.
