# Attack 01 Detection – ICMP Echo Request Detection

## Overview

This detection identifies ICMP Echo Request packets within a packet capture. ICMP Echo Requests are commonly generated by the `ping` utility and are frequently used during the host discovery phase of network reconnaissance.

This implementation demonstrates a simple signature-based detection approach using Python and PyShark to identify host discovery activity in a controlled cyber range.

---

## Detection Objective

Detect ICMP Echo Request (Type 8) packets captured during the host discovery attack performed in Phase 2.

---

## Detection Logic

The detection script performs the following steps:

1. Opens the supplied PCAP file.
2. Filters ICMP traffic using PyShark.
3. Checks whether the ICMP Type equals **8 (Echo Request)**.
4. Records:
   - Timestamp
   - Source IP
   - Destination IP
5. Displays a summary of all detected events.

---

## Implementation

Detection script:

```
detections/python/detect_icmp.py
```

The script accepts a PCAP file as a command-line argument:

```bash
python detections/python/detect_icmp.py captures/phase-2/attack-01/attack01_ping.pcap
```

---

## Potential False Positives

Legitimate ICMP Echo Requests may be generated by:

- Network administrators
- Monitoring systems
- Availability checks
- Diagnostic troubleshooting

For this reason, an ICMP Echo Request should be treated as an indicator of reconnaissance only when considered alongside additional contextual information.

---

## Limitations

This implementation:

- Detects only ICMP Echo Requests (Type 8).
- Does not distinguish between legitimate and malicious ping activity.
- Operates on offline PCAP files rather than live traffic.
- Does not correlate activity across multiple hosts or time windows.

---

## Defender Perspective

Although simple, ICMP monitoring provides defenders with visibility into early-stage network reconnaissance. Detecting repeated Echo Requests can help identify host discovery activity before more advanced reconnaissance or exploitation attempts occur.

---

## Key Takeaways

- ICMP Echo Requests are a common indicator of host discovery.
- Packet captures provide sufficient evidence to identify reconnaissance activity.
- PyShark enables straightforward packet inspection using Wireshark dissectors.
- Simple, explainable detections form the foundation for more advanced network monitoring techniques.
