# Attack 02 Detection – TCP SYN Scan Detection

## Overview

This detection identifies potential TCP SYN scan activity by analyzing TCP SYN packets within a packet capture. Rather than detecting individual packets, the detection focuses on behavioral patterns by identifying hosts that initiate TCP connections to a large number of unique destination ports.

The implementation uses Python and PyShark to inspect captured traffic and applies a configurable threshold to identify potential scanning activity.

---

Detect TCP SYN scan activity generated during the Phase 2 network reconnaissance exercise.

## Detection Logic

The detection performs the following steps:

1. Opens the supplied PCAP file.
2. Filters TCP traffic using PyShark.
3. Identifies TCP packets with only the SYN flag set (`0x0002`).
4. Groups SYN packets by source IP address.
5. Tracks:
   - Total SYN packets
   - Unique destination ports
6. Compares the number of unique destination ports against a configurable threshold.
7. Reports hosts that exceed the threshold as potential TCP SYN scanners.

---

## Detection Strategy

Unlike signature-based detection, this implementation identifies scanning **behavior**.

A normal client typically initiates TCP connections to a small number of services. In contrast, a SYN scan rapidly sends SYN packets to many different destination ports in order to discover available services.

Monitoring the number of unique destination ports contacted by a source host provides a simple and explainable method for identifying reconnaissance activity.

---

## Implementation

Detection script:

```
detections/python/detect_syn_scan.py
```

Example execution:

```bash
python detections/python/detect_syn_scan.py captures/phase-2/attack-02/syn_scan.pcap
```

Thresholds can also be customized:

```bash
python detections/python/detect_syn_scan.py captures/phase-2/attack-02/syn_scan.pcap --threshold 100
```

---

## Potential False Positives

Similar traffic patterns may be generated by:

- Authorized vulnerability scanners
- Asset discovery tools
- Network inventory systems
- Security assessment platforms
- Legitimate penetration testing activities

Detection results should therefore be interpreted alongside environmental context and authorized scanning schedules.

---

## Limitations

This implementation:

- Operates on offline PCAP files.
- Uses a threshold-based detection strategy.
- Does not distinguish between authorized and unauthorized scanning.
- Does not correlate activity across multiple captures or time windows.
- Focuses exclusively on TCP SYN scan behavior.

---

## Defender Perspective

TCP SYN scans are commonly used during the reconnaissance phase of an attack to identify exposed network services. Detecting scanning activity provides defenders with an opportunity to identify suspicious behavior before exploitation attempts begin.

Behavior-based detections such as monitoring the number of unique destination ports can provide effective early warning without relying on complex intrusion detection systems.

---

## Key Takeaways

- TCP SYN scans generate large numbers of SYN packets to different destination ports.
- Counting unique destination ports provides a simple behavioral detection method.
- Configurable thresholds allow the detection to be adapted to different network environments.
- PyShark enables efficient packet analysis using Wireshark dissectors.
- Lightweight behavioral detections can effectively identify reconnaissance activity in a controlled cyber range.
